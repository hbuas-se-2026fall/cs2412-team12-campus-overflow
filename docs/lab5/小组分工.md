## 0. 分工原则（与 Lab 4 一致）

1. **按"可独立验证的产物"分**：一个模块 / 一层 / 一个提交物，能单独 review、单独演示。
2. **作者不自评**：每个 PR 必须由另一人 review + LGTM，SM 才合并。
3. **每人有备份**：任何一人缺勤，备份能接着讲、接着改。
4. **前后端不割裂**：负责前端页面的人必须知道后端契约，负责后端接口的人要自己跑一遍前端。
